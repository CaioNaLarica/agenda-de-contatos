# Agenda de Contatos

Projeto da aula de Flutter para cadastrar, editar e excluir contatos, com os dados salvos no SQLite.

Tem validação de e-mail, foto pela câmera ou galeria e consulta de endereço pelo CEP usando o ViaCEP. O número e o complemento são preenchidos manualmente.

[Baixar o APK](https://github.com/CaioNaLarica/agenda-de-contatos/releases/latest/download/agenda-contatos.apk)

Para rodar o projeto com o Flutter instalado:

```bash
flutter pub get
flutter run
```
